증감은 지표별 직전 성공 수집 대비입니다. 수집 시각은 한국 시간입니다.

공통 수집·집계 기준

출처: YouTube Data API · YouTube Analytics API · Instagram Graph API. 수집 시각은 페이지 상단에 한국 시간(KST)으로 표시합니다.

YouTube 조회수는 채널 누적 조회수입니다. Instagram 조회수는 접근 가능한 게시물의 누적 조회수 합계(최대 300개)로, 두 플랫폼을 합산하지 않습니다.

유효 조회수는 대시보드 기준 YouTube Analytics의 오늘 포함 최근 90일 쇼츠 engagedViews입니다. 롱폼은 최근 365일 VOD 시청 시간입니다. Studio 수익 창출 탭 직접 확인값이 아닙니다.

이 페이지는 표시된 수집 시각의 공개 리포트입니다. 페이지 새로고침은 발행된 최신 리포트를 다시 읽으며, 플랫폼 API를 실시간 호출하지 않습니다.

신규 채널 The Silent Alpha는 공통 수집기 등록 전으로 현재 지표 미확인입니다.
