증감은 지표별 직전 성공 수집 대비입니다. 수집 시각은 한국 시간입니다.

공통 수집·집계 기준

출처: YouTube Data API · YouTube Analytics API · Instagram Graph API. 수집 시각은 페이지 상단에 한국 시간(KST)으로 표시합니다.

YouTube 조회수는 인증된 YouTube Analytics API의 전체 기간 조회수입니다. Studio 실시간 추정치와 처리·반영 시점이 다를 수 있습니다. 수익 창출 지표는 Studio 확인값만 표시하며, 미확인은 0이 아닙니다. 구독자 수는 공통 Data API 수집값입니다. Instagram 조회수는 접근 가능한 게시물의 누적 조회수 합계(최대 300개)로, 두 플랫폼을 합산하지 않습니다.

쇼츠 참여 조회수는 공통 대시보드의 YouTube Analytics API engagedViews이며 최근 90일 쇼츠 범위입니다. 수익 창출 심사 지표와 별도로 표시하고 같은 지표의 과거 기록만 비교합니다.

유효 조회수는 YouTube Studio 수익 창출 탭의 최근 90일 유효 공개 쇼츠 조회수입니다. 롱폼은 같은 탭의 최근 365일 유효 공개 시청 시간입니다. 참여 조회수(engagedViews)와 일반 시청 시간으로 대체하지 않습니다. Studio 확인 시각과 화면 집계 기준일을 지표별로 표시합니다. 이전 API 기준 조회수·참여 조회수는 새 지표의 비교 및 그래프에서 제외합니다.

이 페이지는 표시된 수집 시각의 공개 리포트입니다. 페이지 새로고침은 발행된 최신 리포트를 다시 읽으며, 플랫폼 API를 실시간 호출하지 않습니다.

미수집 지표는 미확인으로 표시합니다. 수익 창출 심사 지표는 Studio 직접 확인값이 있을 때만 표시합니다.
